# CineSync — Персональный медиасервер & Watch Together

Современный, производительный и бесплатный аналог Plex / Jellyfin со встроенной социальной платформой и сверхточной синхронизацией совместного просмотра (Watch Together).

## 🚀 Возможности
- 🎬 **Поддержка любых форматов**: MKV, MP4, AVI, HEVC/H.265, H.264, AV1, 10-bit HDR, многоканальный звук DTS-HD, TrueHD, Dolby AC3/EAC3 через на лету работающий движок FFmpeg (Direct Stream / HLS Transcode с аппаратным ускорением Nvidia NVENC, Intel QSV, AMD AMF).
- ⚡ **Сверхточная синхронизация Watch Together**: NTP-синхронизация локальных часов с серверными (учет RTT/пинга), плавная микро-коррекция скорости (`0.98x - 1.02x`) без заиканий звука и одновременный Lockstep запуск.
- 👥 **Система друзей и комнат**: Полноценная регистрация/авторизация (первый зарегистрированный аккаунт — Администратор), список друзей онлайн со статусом активности («Смотрит Начало»), отправка приглашений в комнату в 1 клик.
- 💬 **Интерактивный кинозал**: Живой чат комнаты и анимированные летающие эмодзи-реакции поверх экрана.
- 🛠 **Панель управления сервером**:
  - Управление медиа-папками на диске и автосканирование библиотек.
  - Живой мониторинг нагрузки (CPU, RAM, диски, видеокарты GPU, активные транскод-сессии с FPS и скоростью).
  - Интеграция с TMDB API (автозагрузка постеров, описаний, жанров и рейтингов).
  - Управление зарегистрированными пользователями и ролями.

## 🏃 Запуск проекта

### 1. Запуск в режиме разработки:
```bash
# Запуск сервера и веб-клиента одновременно:
npm run dev

# Или раздельно:
npm run dev:server  # API & WebSockets на http://localhost:5000
npm run dev:client  # Web UI на http://localhost:3000
```

### 2. Запуск в продакшн-режиме (All-in-one сервер на порту 5000):
```bash
npm run build
npm start
```
После запуска откройте в браузере: **http://localhost:5000** (или http://localhost:3000 в dev-режиме).

```
d:/MyPlex/
├── media/               # Локальные папки с медиафайлами
│   └── movies/          # Папка фильмов (включая сгенерированный тестовый фильм Inception 2010)

├── server/              # Backend (Node.js, Express, Socket.io, FFmpeg, better-sqlite3)
└── client/              # Frontend (React, Vite, TypeScript, Tailwind CSS, Lucide Icons, Hls.js)
```
